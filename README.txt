PROJECT PERGAMON — static site (WYSIWYG-ready)

EDIT THESE PAGES:
  index.html         Home
  faq.html           FAQ
  field-notes.html   Field Notes
  get-involved.html  Get Involved

SHARED:
  styles.css   all colours, type, spacing (change the look in one place)
  site.js      mobile menu toggle only
  assets/      serpent emblems, parchment texture
  favicon.ico, icon.svg, apple-touch-icon.png, og-image.png  (site root)

HOW TO EDIT:
  Open any .html in your visual/WYSIWYG editor. Keep the whole folder together
  so styles.css and assets/ resolve. Header and footer are repeated in each page
  (static site) — edit them in each file, or use your editor's template feature.

FILL THESE PLACEHOLDERS:
  Add sources/links anywhere as normal <a href="...">...</a>.

FONTS: Marcellus + Spectral load from Google Fonts via the <link> in each <head> (needs internet).

DEPLOY: upload the whole folder to any static host (Netlify, Cloudflare Pages, GitHub Pages...).
