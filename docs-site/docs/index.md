# The ARCHI Standard

**ARCHI** — *Archiving the ReConstructible History of Intelligence* 

Technical documentation by **Project Pergamon** for ARCHI, an AI-native archival format. 

Pergamon is an independent effort to preserve publicly released components that enable researchers to interpret the behavior of AI models (their weights, their provenance, and the
record of how they came to be). This site opens a discussion on the standards that make such an effort possible possible.

## What's here

- **[The ARCHI Profile, v0.1](spec.md)** — a draft profile of the BagIt packaging standard
  (RFC 8493) that constrains a bag to carry one publicly released AI model as a
  self-describing, verifiable preservation unit.
- **[The markedness vocabulary](vocabulary.md)** — how the ARCHI profile keeps custodians accountable by ensuring that every component of a model is declared *present*, *withheld*, or *undetermined*, so no gap is ever silent.
- **[Validation](validation.md)** — the reference validator, and what it enforces.
- **[Standards crosswalk](crosswalk.md)** — the OAIS mapping, cell by cell, and the
  Governance Docket.
- **[A worked example](example.md)** — a real, validating bag to download and test locally.

!!! note "Draft standard"
    This is v0.1 — a proof of concept, an opening dialogue, and an invitation to
    collaborate: a draft standard with a reference validator. We invite independent
    implementations — a standard only one party can enforce isn't one yet.
    [Get involved](https://projectpergamon.org).
