# Worked example

A complete demonstration tape — one LTO-9 volume carrying one bag (OLMo-7B, chosen as
the reference specimen of a fully open release) — is available for download. The
metadata layer is real and validates; the large binaries are clearly marked stand-ins. Claims about the model's liscence, provinence, size, and other facts are provided with the intent to demonstrate the classification system. Each claim has been checked for factuality by tracing it to reference URLs where possible for illustration purposes. The hope is that a technical demonstration of the format can invite discussion on how to develop better better approaches to anchoring claims as part of the next round of revisions (see S7 "Completeness" & S11 "Considerations for v.02.").
